## What this role usually means

Frontend engineers own user interface quality: component systems, accessibility, performance, state, and visual fidelity. Web-first postings often want CSS architecture, design systems, and browser performance.

## What you actually did on FitGenius

FitGenius is a pre-launch consumer fitness product: iOS and Android (Expo / React Native), Firebase backend (~64 Cloud Functions, Firestore rules, IAP verification, Gemini AI), marketing site (Vite/React), app/legal/admin hosting, store-submission runbooks, and a legal/compliance suite. You were the founding technical partner — one person owning product, code, cloud, QA packets, and founder enablement from roughly May through September 2026.

You shipped a large React Native UI (tabs, workout session, maps, charts, paywall, tour, 21-locale i18n, reduced motion, tablet layouts, VoiceOver-oriented text). You also shipped a Vite + React 19 + Tailwind marketing site with routing, forms, and tests, plus static legal/support/admin pages.

## How that work applies to **Frontend Engineer**

Apply when the job is 'product UI in React/TS' or 'mobile + web frontend.' Stretch when it is a design-system/CSS-architecture web role with no RN. Your deepest frontend craft is in mobile product UX, not in a Storybook token platform.
