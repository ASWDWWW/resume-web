# Restricted records

This folder is a **label** plus gitignore. It is not encryption and not an access-control system.

Tracked in git: this README and `ACCESS.md` only.  
Ignored: everything else you put here.

Do not store secrets that a cloned public repo or a chat upload could leak. Prefer a private vault or a private repository with real permissions.

If an agent needs a fact from a restricted record, the user should paste a redacted excerpt into the ticket.
