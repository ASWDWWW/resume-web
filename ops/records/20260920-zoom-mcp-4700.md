# Zoom MCP error 4700

Date: 20 September 2026.

Cursor catalog Zoom OAuth failed with Zoom `errorCode` 4700 Invalid redirect url. Desktop MCP sent `http://localhost:8787/callback`. Zoom rejects hostname `localhost`. Redirect is not configurable in Cursor.

Workaround: `zoom-bridge` in `~/.cursor/mcp.json` via `ops/integrations/zoom/connect.mjs`. Marketplace rejects `http://127.0.0.1:8788/callback` (Wrong URL format). Bridge OAuth uses HTTPS bounce `https://fitd-fash.github.io/cursor-zoom-oauth-callback/` which forwards to `http://127.0.0.1:8765/callback`. Catalog plugin left in place and expected to stay `needsAuth`. Do not call catalog `mcp_auth`.

20 Sep 2026 follow-up: Windows split `--header-file` on the space in `Zakiy Manigo`, so tool calls hit Zoom without a Bearer and mcp-remote tried DCR. Headers now live at `C:\ProgramData\cursor-zoom-mcp\headers.txt`. Reload zoom-bridge for that to take effect.
