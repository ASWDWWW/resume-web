# Fundraising and investor relations

Command: `/investor-update`.

## Objectives and milestones

**Unresolved** until you set a round, amount, and date. Do not invent traction.

## Research, outreach, pitch, diligence, meetings, updates

Drafts only. Verify recipients. Use dated metrics; if a metric is an estimate, label it.

Sensitive materials: keep out of this public repo when possible. `ops/restricted/` is a label plus gitignore, not encryption.

Traction verification: link the source (store console, Firebase, bank, waitlist count). Unsourced charts are not allowed in an update.
