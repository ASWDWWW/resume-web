## Full workflow prompts

### Project startup

Inspect this workspace first. Preserve unfinished Career, Content, and resume work. Read the control center, project profile, and routing. Use github-aswdwww for this repo. Implement the task; if a connector is down, continue independently. Report built, tested, blocked, optional. Do not send, charge, or deploy unless I said so.

### Workspace repair

Repair native Cursor OS files only. Recreate missing `.cursor/commands`, `hooks.json` scripts, rules, skills, agents. Do not count markdown essays as commands. Do not revert my unfinished file moves.

### Ticket completion

Create or load a ticket, implement acceptance checks, verify on shared surfaces, write a handoff. No commit unless I ask.

### Follow-ups

Use dated records, not memory. Draft only. Confirm sending identity before any send.

### Debugging

Evidence first. Same GitHub identity. Minimal fix. No production deploy.

### Reviews

Use independent-reviewer. Critical / suggestion / optional.

### Releases

Name env and rollback owner. This site is static Firebase. Stop before deploy unless authorized.

### Handoffs

Fill `ops/templates/handoff.md` so the next session does not need this chat.

### Founder pivots

Preserve work, mark superseded requirements, redirect agents, disable stale automations.

### Business analysis

Separate actuals, estimates, forecasts. Label assumptions.

### Marketing

Approved claims only. Canva OK; Figma and Magnific may be unavailable. No paid spend without a cap.

### Finance

Stripe unsupported here; if added later, test mode default. Do not mix actuals and forecasts.

### Legal preparation

Research and handoff. Not legal approval.

### Investors

Dated sourced metrics. Draft only. Keep sensitive files out of public git.

### Communications

Draft. Gmail/Zoom may be unauthenticated. Ask which Gmail identity.

### Integration diagnosis

Verify claims. Do not gh auth switch. Do not record secrets.
