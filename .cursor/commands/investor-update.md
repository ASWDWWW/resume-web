# Investor update or fundraising prep

Read `ops/business-operations/fundraising.md`. Use consistent, dated metrics. Do not mix actuals and projections.

1. Verify traction against source systems or labeled estimates.
2. Draft outreach, pitch edits, or an update. Do not email investors unless the user asked and the sending identity is confirmed.
3. Keep sensitive fundraising material out of git when possible. Use `ops/restricted/` with the access policy, knowing folders are not security.
4. Diligence lists should point to evidence paths, not recreate secrets.

Match the funding objective already in the project profile. If it is an assumption, say so.
